## Architecture

Combric is package-first. Standard CSS is a primary consumer path, React
components do not require Tailwind, and the Tailwind v4 adapter is optional.

- `@combric/tokens` — canonical typed tokens and generated CSS properties.
- `@combric/layout` — framework-independent Grid and Flexbox primitives.
- `@combric/react` — native-first accessible React components.
- `@combric/tailwind` — optional semantic Tailwind v4 adapter.

## Framework status

The current catalogue and package contracts are implemented through COMBRIC-0.9.
These docs describe that verified repository state. Package publication,
production docs deployment, the future CLI, Guard rules, and Combric Studio are
not part of the current release.
