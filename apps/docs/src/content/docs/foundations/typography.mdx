Typography is provider-neutral. The token fallback stacks work without a web
font, while the official default preset, `@combric/fonts`, uses Fontsource to
self-host Inter Variable for body and interface text and JetBrains Mono Variable
for code.

Import the preset after the Combric stylesheet used by the application:

```css
@import "@combric/react/css";
@import "@combric/fonts/css";
```

There is no runtime request to Google or another font service. Fontsource emits
WOFF2 assets from the application build; its default variable CSS uses
`font-display: swap` and `unicode-range`.

To use Google Fonts, Adobe Fonts, a corporate provider, or local font files,
load that provider in the application and override the two public primitive
stacks after the Combric imports:

```css
:root {
  --combric-primitive-font-family-sans:
    "Acme Sans", ui-sans-serif, system-ui, sans-serif;
  --combric-primitive-font-family-mono: "Acme Mono", ui-monospace, monospace;
}
```

The primitive stacks feed the semantic `body` and `code` roles in both built-in
themes. The consuming project remains responsible for the replacement font's
licence and distribution terms.
