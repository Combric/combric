---
title: Metriq
description: Combric's default square, semantic design language.
---

Metriq is Combric's default design language: restrained, editorial, and square.
Its semantic `radius` resolves to the `radius.square` primitive value `0`.

Primitive tokens hold reusable raw values. Semantic tokens name UI purpose and
point to primitives. Components consume semantic CSS properties so canonical
values are defined once without introducing a runtime theme system.

Metriq documents default developer-facing behavior; it is not a brand guideline
or Theme Builder.
