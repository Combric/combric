---
title: Standard CSS
description: Use Combric tokens and layout without Tailwind.
---

Standard CSS is a first-class Combric path.

```css
@import "@combric/tokens/css";
@import "@combric/fonts/css";

.panel {
  color: var(--combric-color-text);
  background: var(--combric-color-surface);
  padding: var(--combric-space-4);
  border-radius: var(--combric-radius);
}
```

`@combric/fonts` is the official Fontsource default and must come after the
other Combric CSS imports so it can bind the public font stacks. Omit it only
when the application deliberately uses its own provider or system-only fonts.

For layout classes, import `@combric/layout/css`. For React components, import
`@combric/react/css` followed by `@combric/fonts/css`.
