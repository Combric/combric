  intended package contract. The `@combric/*` packages are not yet available
  from the public npm registry.

**Install Combric as packages. Use the CLI when you want Combric to configure or
generate things for you.**

The CLI remains optional and currently exposes no commands. Start with
[standard CSS](/getting-started/standard-css/) or
[React](/getting-started/react/). Add [Tailwind](/getting-started/tailwind/)
only when your application already uses Tailwind v4.
