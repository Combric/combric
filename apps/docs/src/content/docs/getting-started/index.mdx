<div class="combric-docs-status">
  <strong>Smallest-package setup.</strong> Start with the package path that
  matches your application, then add optional integrations only when needed.
</div>

**Install Combric as packages. Use the CLI when you want Combric to configure or
generate things for you.**

The CLI remains optional. Start with
[standard CSS](/getting-started/standard-css/) or
[React](/getting-started/react/). Add [Tailwind](/getting-started/tailwind/)
only when your application already uses Tailwind v4. The
[CLI guide](/getting-started/cli/) covers setup and diagnostics for existing
projects. Each new CLI setup includes the optional
[Fontsource preset](/foundations/typography/) by default; you can replace it
with any provider through the public font stacks.
