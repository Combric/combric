---
title: Installation
description: Install the smallest Combric package path for your application.
---

## React components

```sh
npm install @combric/react react react-dom
```

React and React DOM `>=19.0.0 <20` are peer dependencies.

## Tokens only

```sh
npm install @combric/tokens
```

## Framework-independent layout

```sh
npm install @combric/layout
```

## Optional Tailwind adapter

```sh
npm install @combric/tailwind tailwindcss
```

Tailwind CSS must satisfy `>=4.3.0 <5`. Combric does not require the CLI,
Tailwind, or source-copy installation.

## Default typography

```sh
npm install @combric/fonts
```

`@combric/fonts` is the official optional Fontsource preset. It provides Inter
Variable and JetBrains Mono Variable through the public CSS import
`@combric/fonts/css`; import it after the selected Combric stylesheet.
